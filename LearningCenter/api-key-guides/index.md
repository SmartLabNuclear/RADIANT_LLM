# API Key Setup Guides

Step-by-step guides for every API key mentioned in the main [README](../../README.md#api-keys). You only strictly need one of OpenAI or Gemini to run RADIANT-LLM at all; Hugging Face is required for document parsing, everything else is optional.

| Guide | Required? | Free? |
|---|---|---|
| [OpenAI](openai.md) | One of OpenAI or Gemini | No, requires billing |
| [Gemini](gemini.md) | One of OpenAI or Gemini | Yes |
| [Hugging Face](huggingface.md) | Required, document parsing | Yes |
| [Tavily](tavily.md) | Optional, live web search | Yes |
| [LangSmith](langsmith.md) | Optional, tracing/logs | Yes |
| [Google Custom Search](google-custom-search.md) | Optional legacy alternative, most new users should skip this one | Only if you already have access |
