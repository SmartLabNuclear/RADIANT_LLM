What is Generative AI? 02 / 12

AI That Creates, Rather Than Decides

While traditional (discriminative) AI classifies or detects patterns (e.g., "Is this photo a cat?"), Generative AI creates brand-new output matching those learned patterns (e.g., "Synthesize an image of a red cat").

  • Pre-training: Ingesting massive amounts of textual web-corpora.
  • Probability Mapping: Computing mathematical likelihoods of upcoming words.
  • Output: Delivering synthesized text, logic, music, or graphics.
How Large Language Models Work 03 / 12

Tokens, Embeddings, & Self-Attention

LLMs process information via numerical representation. Language is broken into parts called tokens, mapped into vectors, and evaluated sequentially.

  • Tokenization: Splitting textual inputs into sub-word structural elements.
  • Multi-Dimensional Embeddings: Mapping word concepts to coordinates.
  • The Transformer Core: Using "Self-Attention" mechanisms to analyze relations between words simultaneously.

RAG: Retrieval-Augmented Generation 05 / 12

Solving Hallucinations & Context Boundaries

LLMs cannot remember everything, and their pre-training cuts off at a set date. RAG resolves this by pairing your query with custom external reference documents.

  • Retrieve: Searches text from a local database matching your prompt.
  • Augment: Appends those files directly behind your original query.
  • Generate: Hands the augmented context to the model to produce factual answers.
CAG: Cache-Augmented Generation 06 / 12
10x

Latency Reduction

Eliminating database lookup pipelines entirely.

Why CAG?

For applications querying high-use, static business documents, running database searches on every prompt is redundant. CAG utilizes massive context windows by keeping static reference data fully loaded in cache memory.

  • Preloaded datasets directly ready inside LLM context window.
  • Zero pipeline delays—removes vector search latency.
The Model Context Protocol (MCP) 07 / 12

The Universal Connector for AI Context

Prior to MCP, each AI application needed customized integration code to talk to files, databases, or cloud tools. MCP provides an open standard, creating an immediate, uniform interface.

  • Like USB-C: One standard port connects the AI to everything.
  • Open Standard: Any developer can connect systems without vendor lock-in.
MCP Architecture Blueprint 08 / 12

MCP Host

The frontend application running the AI experience (e.g., Claude Desktop, VS Code, or custom software environments).

MCP Client

The component residing inside the Host that initiates and maintains protocol-level connections with the servers.

MCP Server

The small, secure service providing context, tools, files, resources, or API gateways out to the client.

Ecosystem Capabilities & Agent Skills 09 / 12

From Passive Chatbots to Active Agents

By linking standard MCP connections to AI frameworks, models transition from conversational systems to proactive executors.

  • Tools: Executable functions the AI runs directly (e.g., executing code, running SQL queries).
  • Resources: Raw datasets readable by the model (CSVs, APIs, Files).
  • Prompts: Structured templates facilitating deep multi-step workflows.

Securing Agent Operations

Exposing backend system systems to AI introduces novel vulnerabilities. Prompt engineering isn't enough—strict boundaries must be enforced.

Guardrails: Always implement "Human-in-the-Loop" verifications before writing data, executing destructive code, or sending outbound payments.
